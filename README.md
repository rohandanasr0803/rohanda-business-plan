# DCI PLUS — Rohanda Nasr | Business Development Proposal Website

This folder is the ready-to-publish executive website. The single authoritative attachment is:

`assets/DCI_PLUS_Business_Development_Plan.pdf` — the latest 20-page PDF supplied by the proposal author, including the roadmap graphic on the last page.

## Deploy in one minute (Netlify Drop)

1. Open https://app.netlify.com/drop and sign in if prompted.
2. Drag the ZIP file `DCI_PLUS_Proposal_Website_FINAL.zip` onto the upload area; if ZIP upload is not available, unzip and drag the extracted `DCI_PLUS_Proposal_Website_FINAL` folder.
3. Once deployed, copy the public URL shown by the host. THIS is the URL to paste into the email (not the ZIP download link).
4. Test the public URL in a private browsing window and click **Read the 20-page PDF**, **Open definitive proposal · PDF**, and **Download the PDF**.

Alternative: GitHub Pages or Cloudflare Pages support this static website.

## Site contents

- index.html, styles.css, script.js
- assets/DCI_PLUS_Business_Development_Plan.pdf
- assets/90_day_roadmap.png, assets/90_day_roadmap.svg and assets/favicon.svg
- robots.txt (reduces indexing, but not a substitute for access control)

## Privacy warning

This is marked CONFIDENTIAL but a publicly hosted website and PDF are accessible to anyone with the URL. For a restricted proposal use a private/password-protected hosting service, or consider delivering the PDF only by email.
